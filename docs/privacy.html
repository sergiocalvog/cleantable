Privacy Policy for CleanTable

Last Updated: October 10, 2026

1. Overview

CleanTable is an offline, client-side Chrome extension designed to detect, clean, and export web tables into spreadsheets (Excel, Google Sheets, CSV, JSON, SQL, and Markdown). We do not collect, store, transmit, or sell any personal data, web browsing history, or website content.

2. Zero Data Collection

  • No Personal Information: We do not collect names, email addresses, IP addresses, or device identifiers.
  • No Browsing History: We do not track, record, or monitor web pages visited.
  • No Table Data Collection: All table parsing, cleaning, and formatting processes occur strictly in-memory in your local web browser.
  • No Third-Party Analytics: CleanTable contains zero tracking scripts, telemetry, or advertising SDKs.

3. Chrome Permissions & Purpose

Permission Purpose
activeTab Grants temporary access to the active webpage when the user clicks the extension popup to detect tables and show live previews.
scripting Injects table cleaning and visual highlighting scripts into the current tab upon explicit user interaction.
clipboardWrite Allows the 1-click export feature to copy cleaned table data (TSV, CSV, JSON, SQL, Markdown) to your local clipboard.
storage Saves user preferences (formatting options and offline license status) locally on your device via chrome.storage.local.
https://api.gumroad.com/* Verifies PRO license keys against the Gumroad API only when a user actively enters a license key.

4. Remote Code Execution

CleanTable does not use any remote code. All scripts and assets are 100% packaged inside the extension archive in full compliance with Manifest V3 policies.
